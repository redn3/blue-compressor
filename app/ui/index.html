A new version is available

This server runs in a container, which does not update itself. To update it:

  1. Synology Container Manager: open Project, select the Blue Compressor project and click Stop. Under Image, delete the old ghcr.io/redn3/blue-compressor image (or set the image tag in docker-compose.yml to the new version). Then build or start the project again; it downloads the new version.
  2. Docker Compose: docker compose pull, then docker compose up -d.
  3. Docker: docker pull ghcr.io/redn3/blue-compressor:latest, then remove and recreate the container with the same settings.

Your settings, watch folders and compressed clips stay as they are. What's new. Set UPDATE_CHECK=false to turn these checks off.
